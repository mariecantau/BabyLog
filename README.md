# BabyLog

BabyLog is a full-stack web application built collaboratively during the Le Wagon bootcamp.

The application was designed to help parents track and manage information related to their baby's daily life in one place.

## Project Context

BabyLog was developed as a team project during Le Wagon, providing hands-on experience with collaborative software development and a complete Ruby on Rails application.

The project involved working with Git branches, pull requests, shared code ownership and integration within an existing codebase.

## Tech Stack

- Ruby
- Ruby on Rails
- JavaScript
- HTML
- SCSS
- PostgreSQL
- Git & GitHub

## Team Development

This project was built collaboratively by a team of four developers.

The development workflow included:

- Git branching and collaborative version control
- Pull requests and code integration
- Shared feature development
- Debugging and iterative improvements
- Coordination within a common Rails codebase

## Project Status

The original application was deployed during the bootcamp.

The deployment is no longer active, but the source code and development history remain available in this repository as part of my full-stack development experience.
